# Valtera

Plateforme d’expertise immobilière, utilisable sur ordinateur et sur téléphone (application web installable).

Premier module : **Témoins** — saisie de témoins de marché sur le terrain, carte satellite, recherche autour d’un point, études de marché.

- Connexion avec un compte Google, accès sur invitation (propriétaire, collaborateur, lecteur).
- Données dans Firebase (Firestore), protégées par des règles de sécurité côté serveur.
- Fonctionne hors ligne : consultation et saisie, envoi au retour du réseau.

Modules prévus : fiches de visite, dossiers, assistant IA.
